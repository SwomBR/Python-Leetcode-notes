## 📖 What Each Problem Note Includes

Each completed problem is intended to include:

1. **Problem overview** — a clear explanation in beginner-friendly language.
2. **Examples and constraints** — understand the inputs and expected outputs.
3. **Real-life analogy** — connect the problem to something familiar.
4. **Step-by-step logic** — plan the solution before writing code.
5. **Brute-force solution** — start with a straightforward approach.
6. **Optimized Python solution** — learn a more efficient approach where applicable.
7. **Line-by-line explanation** — understand what the code does.
8. **Dry run** — follow the algorithm with sample input.
9. **Concepts and patterns** — identify reusable problem-solving techniques.
10. **Time and space complexity** — understand performance.
11. **Edge cases and common mistakes** — learn how to avoid bugs.
12. **Practice and revision notes** — reinforce the concepts.

> **Learning principle:** Understand the logic first, write the code second, and optimize it third.

## 🚀 How to Use This Repository

1. Choose a problem from a topic folder.
2. Read the problem explanation carefully.
3. Try to solve it yourself before looking at the solution.
4. Study the brute-force approach.
5. Understand the optimized approach and its trade-offs.
6. Trace the code using the dry run.
7. Reimplement the solution without copying.
8. Revisit the problem later to test your understanding.
